# MCoT+VG Accuracy-Aligned Evaluation Package

This package is designed to make the experimental claims safe, reproducible, and aligned with the actual numbers.

It implements five configurations:

1. **Baseline**: direct LLaVA answer on the original image.
2. **MCoT-v2**: concise multimodal reasoning that uses visible evidence plus commonsense/world knowledge.
3. **VG-Crop**: question-conditioned CLIP Grad-CAM, then LLaVA answers using the original image plus a zoomed high-CAM crop.
4. **MCoT+VG-v2**: step-conditioned grounding, crop-based visual evidence, final answer using full image + crop + concise evidence.
5. **MCoT+VG-Router**: optional answer selector over Baseline, VG-Crop, and MCoT+VG-v2 predictions.

The package does **not** hard-code positive claims. It generates paper-ready claim language only after computing accuracy, McNemar tests, bootstrap confidence intervals, and faithfulness deltas.

## Why this version is safer than the previous notebook

- Same sample set and same N for every method.
- Same answer extraction across every method.
- MCoT prompt no longer says “use only visible details”; A-OKVQA often needs commonsense/world knowledge.
- VG is used as **visual evidence** through a crop, not only as a weak text hint.
- No fake HIS/SC/Fleiss κ values. The annotation template is provided separately.
- Faithfulness uses CLIP cosine deletion/insertion instead of saturated sigmoid logits.
- Claims are automatically downgraded if the gain is modest or statistically non-significant.

## Install

```bash
pip install -r requirements.txt
pip install -e .
```

## Minimal run

```bash
python scripts/run_full_eval.py \
  --n 1145 \
  --seed 42 \
  --model_id llava-hf/llava-1.5-7b-hf \
  --methods baseline,mcot,vg_crop,mcot_vg,router \
  --judge strict \
  --out_dir outputs/llava15_v4
```

For Gemini/Vertex semantic judging:

```bash
export GCP_PROJECT="your-project"
export GCP_LOCATION="us-central1"
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/service_account.json"

python scripts/run_full_eval.py \
  --n 1145 \
  --seed 42 \
  --model_id llava-hf/llava-1.5-7b-hf \
  --methods baseline,mcot,vg_crop,mcot_vg,router \
  --judge gemini \
  --gemini_model gemini-2.5-flash \
  --out_dir outputs/llava15_v4_gemini
```

Then generate the report:

```bash
python scripts/make_report.py --out_dir outputs/llava15_v4_gemini
```

## Recommended paper framing

Use `reports/paper_claims.md` generated by `make_report.py`. It will choose one of these frames automatically:

- **Positive accuracy claim** only if MCoT+VG beats Baseline and McNemar p < 0.05.
- **Modest accuracy claim** if MCoT+VG has the best accuracy but p ≥ 0.05.
- **Accuracy-preserving interpretability claim** if accuracy is statistically tied but faithfulness improves.
- **Trade-off claim** if MCoT+VG lowers accuracy but improves faithfulness.

## Human annotation

Create a real HIS/SC annotation sheet:

```bash
python scripts/make_annotation_template.py --out_dir outputs/llava15_v4_gemini --n_items 100
```

Do not report HIS, SC, or Fleiss' κ until five human annotators complete the sheet.
